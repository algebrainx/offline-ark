    So richtest du den Chat ein

    Du hast diese Seite direkt als Datei geöffnet. Der Chat braucht einen kleinen Server auf einem Gerät (Laptop oder Raspberry Pi). Die anderen öffnen dann nur eine Adresse im Browser.

    1. Node.js installieren Auf dem Laptop oder Raspberry Pi: Node.js ab Version 16 installieren (nodejs.org). Das geht einmal mit Internet; danach läuft alles ohne. Lade den Installer am besten schon jetzt herunter und speichere ihn auf einem USB-Stick. Raspberry Pi: Im Terminal sudo apt install nodejs eingeben und mit node -v prüfen.
    2. Server starten Öffne im Offline-Ark-Ordner ein Terminal (Windows: Rechtsklick in den Ordner, „Im Terminal öffnen“) und tippe: node server/chat-server.js Optional: --pin 1234 verlangt einen Chat-Code, --log speichert die Nachrichten in einer Datei, --port 8081 ändert den Port. Fragt die Windows-Firewall, erlaube den Zugriff nur für „Private Netzwerke“.
    3. Handys verbinden Alle Handys müssen im selben WLAN sein – oder im Hotspot des Laptops. Der Server zeigt beim Start Adressen an, zum Beispiel: http://192.168.1.23:8080/tools/chat.html Diese Adresse im Browser der Handys öffnen. Im Terminal erscheint außerdem ein QR-Code, den du mit der Kamera scannen kannst.

    Kein WLAN vorhanden? Hotspot nutzen

    • Laptop mit Windows: Einstellungen → Netzwerk & Internet → Mobiler Hotspot einschalten. Die anderen verbinden sich mit diesem WLAN. Mehr dazu bei Microsoft.
    • Android-Handy als Hotspot: Einstellungen → Netzwerk & Internet → Hotspot & Tethering → WLAN-Hotspot. Er funktioniert auch ohne Internet. Der Server kann auf einem Laptop laufen, der sich mit diesem Hotspot verbindet.
    • iPhone: Der „Persönliche Hotspot“ funktioniert meist nur mit Mobilfunk-Tarif. Nimm besser einen Laptop oder ein Android-Handy als Hotspot.
    • Raspberry Pi als Hotspot: Mit Raspberry Pi OS (NetworkManager) erzeugt dieser Befehl ein eigenes WLAN, zum Beispiel sudo nmcli device wifi hotspot ssid Offline-Ark password MeinGeheimesWort. Danach den Server auf dem Pi starten. Die Adresse zeigt der Server an. Mehr zum Befehl: nmcli.

    Raspberry Pi: Chat beim Einschalten automatisch starten

    Ein Beispiel für einen systemd-Dienst steht in der Datei server/README.md im Offline-Ark-Ordner.

    Wichtig zur Sicherheit

    • Nur im eigenen WLAN oder Hotspot verwenden, nie ins Internet freigeben.
    • Es gibt keine Verschlüsselung. Wer im Netz ist, kann mitlesen.
    • Nachrichten sind nur Text. Bilder und Dateien werden nicht übertragen.
    • Ein Chat ersetzt keinen Notruf: Bei Gefahr zuerst 112 wählen, wenn das Telefonnetz geht.
