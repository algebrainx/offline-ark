QR-Code

QR-Codes für Text, Koordinaten und Kontakte erzeugen, komplett offline.

Süd und West sind negativ (z. B. −33.86). Der Code enthält geo:Breite,Länge – Karten-Apps öffnen ihn direkt.

Wer den Code scannt, kann direkt anrufen.

Sicherheit

Das Passwort steht lesbar im Code. Zeige ihn nur Menschen, denen du vertraust.

Die Beschriftungen im Code sind immer Deutsch, damit Rettungskräfte in Deutschland ihn lesen können. Zeige den Code nur, wenn du es willst: Er enthält Gesundheitsdaten.

Fehlerkorrektur

QR-Code scannen

Nutze die Kamera-App deines Handys, um QR-Codes zu lesen.


      

        
      

    

  


  

    Tipps
    
    
      
  • Kurze Texte ergeben kleine, gut lesbare Codes. Ab etwa 150 Zeichen wird der Code dicht – dann groß anzeigen oder drucken.
    • 
      
  • Teste den Code, bevor du dich darauf verlässt: Scanne ihn mit einem zweiten Handy.
    • 
      
  • Mit Fehlerkorrektur H ist der Code auch bei Schmutz oder Knicken lesbar, wird aber größer.
    • 
      
  • Der Code wird nur auf diesem Gerät berechnet. Nichts wird gesendet oder gespeichert.
